# Jetson DCVC Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a Chinese Gradio controller and validate actual HT-S bitstream coding on the encoder Jetson.

**Architecture:** Background Python worker, bounded capture queue, upstream codec adapter, validated TCP transport and separate preview. Independent decoder entry point.

**Tech Stack:** Miniforge Python 3.10, NVIDIA Torch CUDA 12.6, DCVC-UF HT-S, OpenCV, Gradio.

**Spec:** docs/superpowers/specs/2026-10-29-demo-design.md

## Global Constraints

- Preserve system CUDA/Torch. Store code under the Desktop project directory.
- 640x360, target 30fps, target end-to-end latency <=500ms; no claimed pass without measurement.
- Eight-frame HT-S chunks and actual entropy-coded bytes; no codec substitution.
- Camera and second Jetson absent; disclose untested acceptance items.

## Review Focus

- Stop/pause while codec initializes must not leave camera or worker running.
- Invalid/unbounded network lengths or metadata must be rejected before allocation.
- Missing camera, checkpoint or extension must produce useful recoverable errors.
- Frame counters must not confuse preview updates with display or codec FPS.
- Slow codec must bound capture backlog; resume must refresh codec state.

### Task 1: Environment and codec feasibility
Files: tools/, patches/, reports/, environment.yml.
- [ ] Install Miniforge locally, create Python 3.10 environment, install compatible NVIDIA wheel and dependencies.
- [ ] Compile upstream CPU and CUDA extensions with bounded jobs; save logs and local compatibility patches.
- [ ] Obtain official checkpoints and verify independent encode/decode on generated 640x360 input; record real byte size and wall time. If blocked, record exact failure and keep UI codec gate truthful.

### Task 2: Configuration, framing and statistics
Files: demo/config.py, demo/transport.py, demo/metrics.py, tests/test_core.py.
Interfaces: Settings(width,height,fps,qp,mode,source,peer,bind); send_packet(sock, metadata, bytes), recv_packet(sock); WindowStats.add(frames,bytes), snapshot().
- [ ] Write and run failing unittest cases for invalid config, fragmented reads, oversized payload, truncation and rolling rates that fall to zero during stalls.
- [ ] Implement minimum standard-library logic and run python -m unittest discover -s tests -v.

### Task 3: Codec adapter and worker
Files: demo/codec.py, demo/engine.py, demo/receiver.py, tests/test_engine.py.
Interfaces: Codec.encode(frames,qp)->packet, Codec.decode(packet)->RGB frames; Engine.start(settings), pause(), stop(), snapshot(); receiver --bind wired-IP.
- [ ] Write failing lifecycle/capture-backlog tests with a controlled slow codec at the hardware boundary.
- [ ] Implement synthetic/camera input, actual upstream adapter, stop/resume safety, local and TCP modes.
- [ ] Run the whole suite and available actual GPU round-trip checks.

### Task 4: Gradio, launch, documentation and review
